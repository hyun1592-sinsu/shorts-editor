## 🎙 목소리 입히기 (편집기 장면 목록 위)

목소리를 하나 고르고, 적용 범위(목소리가 없는 장면만 · 모든 장면 · 선택한 장면만)를 고르면 돼요. 장면마다 다른 목소리를 입혀도 됩니다.

| 목소리 | 하는 일 | 기기 |
|---|---|---|
| **기본 목소리** (스튜디오 목소리 목록) | 스튜디오가 만든 WAV를 장면마다 자동으로 넣음. 밤새 만들어 둔 같은 문장·목소리·억양·속도가 있으면 바로 가져옴 | 기본 목소리 PC가 켜져 있으면 어디서나 |
| **브라우저 목소리** | 이 기기의 TTS로 읽음 (MP4 내보내기 때 컴퓨터에서 화면 공유로 녹음) | 기기마다 목소리가 다름 |
| **직접 녹음** | 편집기 옆에 녹음기가 열리고, 녹음하면 그 장면에 바로 들어감 | 어디서나 |
| **스튜디오에서 녹음** | 스튜디오 화면을 편집기 옆에 엶 | 기본 목소리 PC가 켜져 있으면 |

위쪽 **녹음기 고르기**(직접 녹음 · 기본 목소리)는 「같이 쓰기」·「녹음만」에서 열 녹음기예요. **⚙**는 이 기기에서 쓸 스튜디오 주소예요.

## 🌙 밤샘 일괄 (스튜디오 세 번째 탭)

1. 대본 여러 편을 `---` 줄로 나눠 붙여 넣어요 (맨 윗줄 `# 제목`은 선택).
2. 목소리 여러 개 × 억양 여러 개, 속도를 골라요. 대본 × 버전마다 한 묶음씩 만들어져요.
3. **🌙 대기열에 걸기**를 누르면 서버가 밤새 차례로 만들어요. 남은 일이 있는 동안 PC는 절전 모드로 들어가지 않아요 (화면은 꺼져도 돼요). 이미 만든 문장·버전은 건너뛰어요.
4. 다음 날 편집기에서 같은 목소리·억양·속도로 **목소리 입히기**를 하면 바로 들어가요. 각 묶음은 **⬇ 저장**으로 `01_`, `02_` 순서의 zip으로도 받을 수 있어요 (편집기 「녹음 파일 넣기」에 그대로 넣어도 순서가 맞아요).

문장은 편집기와 똑같은 규칙으로 나눠요. 그래서 편집기에서 대본을 나눈 장면과 그대로 짝이 맞아요.

## 다른 기기에서 스튜디오 쓰기 (휴대폰 · 노트북)

스튜디오의 AI 모델과 목소리 원본은 기본 목소리 PC에 있어요. 다른 기기에서 쓰려면 그 PC를 안전하게 연결해야 해요. **Tailscale**(무료, 내 기기끼리만 연결)을 권해요.

1. 기본 목소리 PC와 다른 기기 모두에 Tailscale을 설치하고 같은 계정으로 로그인해요.
2. 기본 목소리 PC에서 `tailscale serve --bg 8777`을 실행해요. 그러면 `https://PC이름.tailXXXX.ts.net/` 주소가 생겨요.
3. 다른 기기의 편집기 위쪽 **⚙**에 그 주소를 넣어요 (기기마다 한 번).

스튜디오를 인터넷 전체에 공개(포트 열기, 공개 터널)하지는 마세요. 주소를 아는 누구나 내 목소리로 음성을 만들 수 있게 돼요.

## 기본 목소리 PC 파일 바꾸기 (이 저장소가 바뀌었을 때)

PC의 `C:\Users\aaa\my-voice\recorder` 폴더에 이 폴더의 `server.py`, `tts.py`, `index.html`, `recorder-bridge.js`를 덮어쓰고 서버를 다시 켜요.

## 보안 · 개인정보

- 스튜디오 서버는 **이 PC 안(127.0.0.1)에서만** 열려요. 다른 PC나 인터넷에서는 들어올 수 없어요.
- 브라우저에서 스튜디오를 부를 수 있는 곳은 `server.py`의 `EDITOR_ORIGINS`에 적힌 주소(GitHub 편집기, localhost:8765)뿐이에요. 다른 웹사이트가 몰래 녹음을 덮어쓰거나 음성을 만들게 할 수 없어요.
- **목소리 녹음(`dataset/`, `voices/`, `outputs/`)은 GitHub에 올리지 마세요.** 공개 저장소는 누구나 내려받을 수 있어서, 목소리 복제나 사칭에 쓰일 수 있어요. `.gitignore`가 wav·mp3 등을 막고 있어요.

## 주고받는 메시지 (개발용)

**🎙 목소리 입히기**의 기본 목소리는 스튜디오의 HTTP API를 그대로 써요: `GET api/tts/voices` → `POST api/tts/generate`(줄마다 항목 1개) → `GET api/tts/items`를 2초마다 확인 → `GET api/tts/audio/{id}`. 멈추면 기다리던 줄을 `POST api/tts/delete`로 지워요.

**같이 쓰기 / 녹음만**은 postMessage를 써요 (`recorder-bridge.js`). 모든 메시지에는 `sv: 1`이 붙어요. 편집기는 **자기가 연 창**이 보낸 메시지만 받아요.

| 방향 | type | 내용 |
|---|---|---|
| 스튜디오 → 편집기 | `hello` | 연결 시작. 편집기가 `script`로 답함 |
| 스튜디오 → 편집기 | `get-script` | 장면 목록 다시 받기 |
| 스튜디오 → 편집기 | `select` | `id` 또는 `no`(1부터) |
| 스튜디오 → 편집기 | `voice` | `id`/`no`, `name`, `mime`, `data`(Blob/ArrayBuffer), `ref` |
| 편집기 → 스튜디오 | `script` | `title`, `selectedId`, `scenes[]` (`id`, `no`, `text`, `silent`, `voice`) |
| 편집기 → 스튜디오 | `select` | `id`, `no` |
| 편집기 → 스튜디오 | `voice-ok` / `voice-error` | `ref`, `id`, `no`, `dur` / `reason` |

## 자연스러운 목소리 설정 (기본값)

| 설정 | 값 | 이유 |
|---|---|---|
| 억양 | 차분 0.7 · 보통 0.85 · 풍부 1.0 | 0.6 아래는 단조롭게 읽어요 |
| 한 번에 읽기 | 켜짐 | 문장 사이 억양이 이어져요 |
| 느낌표를 차분하게 | 꺼짐 | "!"의 감정을 살려요 |
| 잡음 제거 | 기준 녹음에만 | 만든 음성을 다시 거르면 금속성 소리가 나요 |
| 속도 | 1.0 | 속도를 바꾸는 처리를 하지 않아요 |

## 기준 목소리 추가 (가지고 있는 녹음 파일 쓰기)

- 기본 목소리 화면 → 음성 만들기 → **기준 목소리 추가**에서 파일 · 이름 · 대본(녹음에서 한 말 그대로)을 넣어요.
- 또는 `voices` 폴더에 `이름.wav`(mp3 · m4a도 돼요)와 같은 이름의 `이름.txt`(대본)를 넣어도 돼요.
- 대본을 비우면 목소리 색깔만 따라 해서 덜 비슷해요. 10~20초, 말하듯 녹음한 파일이 가장 좋아요.
