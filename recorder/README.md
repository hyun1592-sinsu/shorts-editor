# 내 목소리 스튜디오 ↔ 숏츠 편집기

## 한눈에 보기

| 무엇 | 어디서 돌아가나 | 주소 |
|---|---|---|
| 숏츠 편집기 | GitHub 페이지 (어느 PC에서나) | https://hyun1592-sinsu.github.io/shorts-editor/ |
| 내 목소리 스튜디오 (녹음 · 내 목소리 AI) | **내 PC** (`server.py`) | http://127.0.0.1:8777/ |

목소리 AI 모델(Qwen3-TTS)과 목소리 원본(`voices/`, `dataset/`)은 PC에 있어야 해요. GitHub 페이지는 html·js만 실행할 수 있어서 스튜디오 서버는 PC에서 켜야 합니다. 편집기는 GitHub 주소로 열고, PC의 스튜디오와 바로 주고받아요.

## 쓰는 법

1. PC에서 스튜디오를 켜요 (`my-voice` 폴더에서):
   ```
   .venv\Scripts\python.exe recorder\server.py
   ```
2. 편집기를 GitHub 주소로 열어요.
3. 둘 중 하나를 골라 써요.
   - **🎙 내 목소리** (장면 목록 위 버튼): 장면 문장을 스튜디오로 보내 내 목소리로 만든 뒤 **장면마다 자동으로 넣어요.** 목소리·억양·속도를 고르고, 「목소리가 없는 장면만」 또는 「모든 장면 새로 만들기」를 고르면 돼요.
   - **같이 쓰기 / 녹음만** (위쪽 버튼): 스튜디오 화면을 편집기 옆이나 따로 창으로 열어요. 학습용 녹음을 하거나, 「📥 편집기 대본 가져오기」로 대본을 넣고 직접 만들 수 있어요.
4. 장면이 모두 내 목소리로 채워지면 **MP4 내보내기**에서 화면 공유 녹음 없이 바로 만들어져요.

처음 연결할 때 브라우저가 **「로컬 네트워크의 기기에 접근」**을 물으면 **허용**을 눌러 주세요. GitHub 주소의 편집기가 내 PC(127.0.0.1)에 접속하려면 이 허락이 필요해요.

## 작업 모드 (편집기 위쪽 버튼)

| 모드 | 화면 | 쓰는 때 |
|---|---|---|
| **편집만** | 편집기만 | 꾸미기·내보내기만 할 때 (🎙 내 목소리 버튼은 여기서도 동작) |
| **같이 쓰기** | 편집기 오른쪽에 스튜디오 | 녹음하거나 목소리를 직접 들어 보며 고를 때 |
| **녹음만** | 스튜디오를 따로 창으로 | 녹음에 집중할 때, 모니터 두 대를 쓸 때 |

스튜디오 주소가 다르면 편집기 위쪽 **녹음기 ⚙**로 바꿔요.

## PC 파일 바꾸기 (이 저장소가 바뀌었을 때)

PC의 `C:\Users\aaa\my-voice\recorder` 폴더에 이 폴더의 아래 3개 파일을 덮어써요. `tts.py`는 그대로 써도 돼요.

- `server.py`: 편집기에서 오는 요청 허용, 다른 사이트 차단
- `index.html`: 「편집기 대본 가져오기」 버튼
- `recorder-bridge.js`: 편집기와 연결하는 파일

## 보안 · 개인정보

- 스튜디오 서버는 **이 PC 안(127.0.0.1)에서만** 열려요. 다른 PC나 인터넷에서는 들어올 수 없어요.
- 브라우저에서 스튜디오를 부를 수 있는 곳은 `server.py`의 `EDITOR_ORIGINS`에 적힌 주소(GitHub 편집기, localhost:8765)뿐이에요. 다른 웹사이트가 몰래 녹음을 덮어쓰거나 음성을 만들게 할 수 없어요.
- **목소리 녹음(`dataset/`, `voices/`, `outputs/`)은 GitHub에 올리지 마세요.** 공개 저장소는 누구나 내려받을 수 있어서, 목소리 복제나 사칭에 쓰일 수 있어요. `.gitignore`가 wav·mp3 등을 막고 있어요.

## 주고받는 메시지 (개발용)

**🎙 내 목소리**는 스튜디오의 HTTP API를 그대로 써요: `GET api/tts/voices` → `POST api/tts/generate`(줄마다 항목 1개) → `GET api/tts/items`를 2초마다 확인 → `GET api/tts/audio/{id}`. 멈추면 기다리던 줄을 `POST api/tts/delete`로 지워요.

**같이 쓰기 / 녹음만**은 postMessage를 써요 (`recorder-bridge.js`). 모든 메시지에는 `sv: 1`이 붙어요. 편집기는 **자기가 연 창**이 보낸 메시지만 받아요.

| 방향 | type | 내용 |
|---|---|---|
| 스튜디오 → 편집기 | `hello` | 연결 시작. 편집기가 `script`로 답함 |
| 스튜디오 → 편집기 | `get-script` | 장면 목록 다시 받기 |
| 스튜디오 → 편집기 | `select` | `id` 또는 `no`(1부터) |
| 스튜디오 → 편집기 | `voice` | `id`/`no`, `name`, `mime`, `data`(Blob/ArrayBuffer), `ref` |
| 편집기 → 스튜디오 | `script` | `title`, `selectedId`, `scenes[]` (`id`, `no`, `text`, `silent`, `voice`) |
| 편집기 → 스튜디오 | `select` | `id`, `no` |
| 편집기 → 스튜디오 | `voice-ok` / `voice-error` | `ref`, `id`, `no`, `dur` / `reason` |
